# NÜGEL

Product website for **NÜGEL**, an Indonesian swim-essentials brand offering sports drink concentrate, anti-fog drops, and starter kits.

## Highlights

- Responsive English and Indonesian website
- Interactive 3D product visuals
- Product and nutritional-information pages
- WhatsApp ordering
- SEO metadata and social-sharing previews

## Tech Stack

Next.js · React · TypeScript · Tailwind CSS · Three.js · React Three Fiber · Cloudflare
